## 6. Observable Singularities: Black Holes as Convergence Boundaries

The Convergence Boundary singularity type introduced in Section 4.2 provides the NSFG model for black holes. A black hole is not a region where the Library ends or where mathematical quantities diverge to infinity. It is a region where observer-relative coherence becomes maximally constrained: all coherent paths converge to a single equivalence class. The observer outside the horizon sees this convergence as a black hole singularity; the observer inside the horizon experiences a different relational structure.

**Definition — Definition 6.1 — Black Hole as Convergence Boundary.** A black hole is an observer-relative Convergence Boundary: a region where the coherent continuation set $\Gamma_O(h,x)$ is nonempty, but every coherent path in $\Gamma_O(h,x)$ converges to the same equivalence class.

$$\forall \gamma_1,\gamma_2 \in \Gamma_O(h,x) \ \mathrm{with}\ x \ \mathrm{inside\ the\ horizon},\ \gamma_1(n) \sim \gamma_2(n)$$

*The convergence is to a single equivalence class, not to a point of infinite density. The class encodes the relational structure of the infalling matter.*

The distinction between the outside and inside observers is crucial. The observer outside the horizon sees all paths converge to a single class—what is conventionally called the singularity. The observer inside the horizon experiences a different relational structure: the paths are still coherent, but their destinations are constrained to a single class. The black hole is therefore a boundary in the observer's accessible reality, not a boundary in the Library itself.

**Definition — Definition 6.2 — Information Convergence (Revised).** This model resolves the information paradox without requiring exotic physics. Information is not destroyed; it converges to an equivalence class. The observer outside the horizon loses the ability to distinguish different infalling states because all coherent paths lead to the same class from that observer's perspective. The observer inside the horizon, however, would see the distinctions that remain resolvable at their resolution.

The key nuance is this: convergence to an equivalence class preserves information in the Library, but not necessarily for the observer. The equivalence class encodes the relational structure of the infalling matter, but different infalling states may map to the same class from the outside observer's perspective. This is not information loss at the ontological level—it is information convergence at the observer-relative level. The outside observer loses the ability to distinguish the states; the Library does not.

$$\mathrm{Information\ is\ preserved\ in}\ \mathcal{M},\ \mathrm{but\ converged\ for\ observer}\ O.\ \forall \gamma_1,\gamma_2 \in \Gamma_O(h,x),\ \gamma_1(n) \sim \gamma_2(n)\ \mathrm{for\ the\ outside\ observer.}$$

*The equivalence class encodes the relational structure of the infalling matter. Different infalling states may map to the same class from the outside observer's perspective. This is a feature of the Convergence Boundary, not a bug. Information is preserved in the Library, but converged for the observer.*

The model makes two testable predictions:

**Testable Predictions of the Convergence Boundary Model**

- Hawking radiation should carry coherence signatures encoding the equivalence class of the infalling matter. If Hawking radiation is purely thermal with no coherence structure, the model is falsified.
- Convergence Boundaries should produce characteristic signatures in the ringdown phase of black hole mergers. If no such signatures are found, the model is challenged.

The coherence signatures in Hawking radiation are the key test. In the standard semiclassical model, Hawking radiation is thermal and carries no information about the infalling matter. In NSFG, the radiation carries the signature of the equivalence class to which the matter converged. This is not a violation of unitarity—it is a manifestation of convergence.

**Formal Statement — Hawking Radiation Coherence Prediction.** Hawking radiation should carry coherence signatures encoding the equivalence class of the infalling matter.

$$\mathrm{Hawking\ radiation\ should\ carry\ coherence\ signatures\ encoding\ the\ equivalence\ class\ of\ the\ infalling\ matter}$$

*If Hawking radiation is purely thermal with no coherence structure, the model is falsified.*

**Formal Statement — Gravitational Wave Echo Prediction.** Convergence Boundaries should produce characteristic signatures in the ringdown phase of black hole mergers.

$$\mathrm{Convergence\ Boundaries\ should\ produce\ characteristic\ signatures\ in\ the\ ringdown\ phase\ of\ black\ hole\ mergers}$$

*If no such signatures are found, the model is challenged.*

The falsification criteria are deliberately explicit. If Hawking radiation is purely thermal with no coherence structure, the Convergence Boundary model is falsified. If gravitational wave echoes show no signatures of convergence, the model is challenged but not falsified—it may require refinement of the coherence model.

This treatment of black holes is a direct consequence of the NSFG framework. The Library is static and complete. The black hole is not a region of the Library where 'math breaks down'. It is a region where the observer's coherent continuation space becomes maximally constrained. The black hole singularity is a feature of the observer's relation to the Library, not a feature of the Library itself.

**Example.** *Setup:* Consider two infalling observers, O₁ and O₂, with different resolution thresholds I_N(O₁) and I_N(O₂). *Result:* Both observers cross the horizon. For the outside observer, their paths converge to the same equivalence class. For O₁ and O₂ themselves, their experiences may differ depending on their resolution thresholds. *Interpretation:* The black hole is a Convergence Boundary for the outside observer. For the infalling observers, the structure of the horizon is determined by their own resolution thresholds. There is no single 'black hole experience'—it is observer-relative.
