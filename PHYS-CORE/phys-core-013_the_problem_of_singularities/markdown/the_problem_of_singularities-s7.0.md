## 7. Falsification Criteria for NSFG Singularities

A scientific framework must be falsifiable. If a theory can accommodate any observation, it explains nothing. NSFG is designed to be falsifiable by design: its predictions are specific, testable, and grounded in the framework's core assumptions. This section establishes the falsification criteria for the NSFG singularity framework, distinguishing between falsification (the model is wrong) and challenge (the model needs refinement).

**Definition — Falsification vs. Challenge.** A falsification criterion is a condition that, if met, would demonstrate that the framework is incorrect. A challenge is a condition that, if met, would demonstrate that the framework needs refinement or additional structure. Falsification is stronger than challenge.

* A single falsification is sufficient to reject the framework. A challenge requires further investigation.

The falsification criteria are grounded in the NSFG framework's core predictions. Each criterion is derived from the framework's axioms and definitions, not imposed from outside. If a criterion is met, the framework is either falsified or challenged.

**Definition — Criterion 1: Coherence-Expansion Mapping.** The NSFG singularity model predicts a relationship between the coherence measure $C(z)$ and the Hubble parameter $H(z)$. Specifically, $H(z) = -\kappa_C \frac{d}{dt}(\ln C(z))$. If this relationship does not hold, the model is falsified.

$$H(z) = -\kappa_C \frac{d}{dt} \ln C(z)$$

*The coherence measure* $C(z)$ *must be independently measurable. The relationship* $H(z) = -\kappa_C \frac{d}{dt}(\ln C(z))$ *is a core prediction of the model. If* $H(z)$ *does not match this relationship, the model is falsified.*

**Formal Statement — Derivation of the Coherence-Expansion Mapping.** The coherence-expansion mapping $H(z) = -\kappa_C \frac{d}{dt}(\ln C(z))$ is derived from the NSFG axioms as follows. The coherence measure $C(z)$ is defined as the observer-relative coherence of a path $\gamma$ through the Library: $C(z) := \mathcal{C}(\gamma \mid O,h,x)$ for a path that traverses a cosmological redshift $z$. The Hubble parameter $H(z)$ is the observer-relative expansion rate: $H(z) := \frac{1}{a}\frac{da}{dt}$, where $a$ is the scale factor. The NSFG framework predicts that cosmic expansion is governed by coherence gradients: $\frac{d}{dt}(\ln C(z)) = -\frac{1}{\kappa_C} H(z)$. Rearranging gives $H(z) = -\kappa_C \frac{d}{dt}(\ln C(z))$. The coupling constant $\kappa_C$ is a derived parameter that relates coherence gradients to expansion rates. It is not a free parameter; it is determined by the observer-relative resolution threshold $I_N(O)$ and the coherence condition $\mathcal{C}(\gamma \mid O,h,x)=1$.

$$C(z) := \mathcal{C}(\gamma \mid O,h,x), \quad H(z) := \frac{1}{a}\frac{da}{dt}, \quad \frac{d}{dt}(\ln C(z)) = -\frac{1}{\kappa_C} H(z), \quad H(z) = -\kappa_C \frac{d}{dt}(\ln C(z)).$$

*The coherence-expansion mapping is derived from the NSFG axioms, not imposed from outside. It is a testable prediction of the framework. If the mapping does not hold, the framework is falsified.*

The coherence-expansion mapping is a specific prediction of the NSFG singularity model. It is derived from the framework's core assumption that singularities are regions of maximal constraint on coherent traversal. If cosmic expansion does not follow this relationship, the framework is falsified.

**Definition — Criterion 2: Black Hole Observations.** The NSFG singularity model predicts that black holes are Convergence Boundaries: regions where all coherent paths converge to a single equivalence class in the observer-relative coherence quotient $\mathcal{M}_C^O$. This predicts specific observational signatures: (1) Hawking radiation must carry coherence signatures encoding the equivalence class of the infalling matter. (2) Gravitational wave echoes must show Convergence Boundary signatures in the ringdown phase of black hole mergers. If these signatures are not observed, the model is challenged.

$$\mathrm{If}\ \mathrm{Hawking}\ \mathrm{radiation}\ \mathrm{is}\ \mathrm{purely}\ \mathrm{thermal}\ \mathrm{with}\ \mathrm{no}\ \mathrm{coherence}\ \mathrm{structure,}\ \mathrm{or}\ \mathrm{if}\ \mathrm{gravitational}\ \mathrm{wave}\ \mathrm{echoes}\ \mathrm{show}\ \mathrm{no}\ \mathrm{Convergence}\ \mathrm{Boundary}\ \mathrm{signatures,}\ \mathrm{the}\ \mathrm{model}\ \mathrm{is}\ \mathrm{challenged.}$$

*This is a challenge, not a falsification. The absence of signatures could be due to observational limitations. However, if the signatures are definitively absent, the model is challenged.*

**Formal Statement — Criterion 2 Details.** The model predicts that Hawking radiation is not purely thermal; it carries coherence structure encoding the equivalence class of the infalling matter. This is a strong prediction that distinguishes NSFG from standard black hole thermodynamics. The model also predicts that gravitational wave echoes in the ringdown phase of black hole mergers show Convergence Boundary signatures. If neither is observed, the model is challenged.

*This criterion is testable with current and near-future observational technology. If the signatures are absent, the model is challenged.*

The black hole criterion is particularly important because it connects the NSFG framework to observable astrophysics. If black holes do not exhibit the predicted coherence signatures, the framework's interpretation of singularities as Convergence Boundaries is challenged.

**Definition — Criterion 3: Dyadic Instability.** The NSFG singularity model predicts that a pure complementary dyad (two opposing motifs) is generically unstable: it cancels, decoheres, or drifts without an independent contextual reference. If a pure dyad can form a stable persistent structure without a third degree of freedom, the model is challenged.

$$\mathrm{If}\ \mathrm{a}\ \mathrm{pure}\ \mathrm{complementary}\ \mathrm{dyad}\ \mathrm{can}\ \mathrm{form}\ \mathrm{a}\ \mathrm{stable}\ \mathrm{persistent}\ \mathrm{structure}\ \mathrm{without}\ \mathrm{a}\ \mathrm{third}\ \mathrm{degree}\ \mathrm{of}\ \mathrm{freedom,}\ \mathrm{the}\ \mathrm{model}\ \mathrm{is}\ \mathrm{challenged.}$$

*This is a challenge, not a falsification. The existence of a stable pure dyad would require additional structure not present in the NSFG framework.*

**Formal Statement — Criterion 3 Details.** The model predicts that dyadic instability is a consequence of the nonempty continuation requirement. A pure dyad lacks an independent contextual reference, so perturbations cannot be corrected. If a stable pure dyad is observed, the model is challenged.

*This criterion is testable in both physical and computational systems. If a stable pure dyad is observed, the model is challenged.*

The dyadic instability criterion is a direct consequence of the NSFG framework's relational coherence structure. A pure dyad is unstable because it lacks the third degree of freedom required for closure. This is a specific prediction that distinguishes NSFG from dyadic frameworks.

**Definition — Criterion 4: O(1) Computational Core.** The NSFG singularity model predicts that the computational cost per observer-relative tick is $\mathcal{O}(1)$, independent of Library size or traversal history. This follows from the coherence quotient: the observer only tracks coherence-distinguishable equivalence classes $\mathcal{M}_C^O(h,x)$, not individual configurations in $\mathcal{M}$. Since the number of accessible equivalence classes is bounded by the observer's resolution threshold $I_N(O)$, the cost per tick is constant. If a physical theory requires exponentially increasing computational resources as the universe ages, the model is challenged.

$$\mathrm{Cost}\ \mathrm{per}\ \mathrm{tick} = \mathcal{O}(1), \mathrm{independent}\ \mathrm{of}\ |\mathcal{M}|\ \mathrm{or}\ h.$$

*This is a challenge, not a falsification. The model predicts* $\mathcal{O}(1)$ *computational cost per tick. If a theory requires exponentially increasing resources, the model is challenged.*

**Formal Statement — Criterion 4 Details.** The model predicts that the computational cost per tick is constant, independent of Library size or traversal history. This is a consequence of the coherence quotient framework: the observer only tracks equivalence classes in $\mathcal{M}_C^O(h,x)$, which are bounded in number by $I_N(O)$. The Library $\mathcal{M}$ may be infinite in cardinality, but the observer never tracks individual configurations — only coherence-distinguishable classes. If a theory requires exponentially increasing resources as the universe ages, the NSFG framework is challenged.

*This criterion is testable in computational models of the universe. If a model requires exponentially increasing resources, the NSFG framework is challenged.*

The $\mathcal{O}(1)$ computational core criterion is a direct consequence of the NSFG framework's coherence quotient. The Library may be infinite, but the observer only tracks what coherence allows. This is a specific prediction that distinguishes NSFG from frameworks with growing ontologies or exponentially increasing computational demands.

**Definition — Criterion 5: Pathological Coherence Breakdown.** The NSFG singularity model predicts that singularities are relational: they depend on the observer's coherence condition. If a singularity appears without the observer's coherence condition changing, the model is challenged.

$$\mathrm{If}\ \mathrm{a}\ \mathrm{singularity}\ \mathrm{appears}\ \mathrm{without}\ \mathrm{the}\ \mathrm{observer's}\ \mathrm{coherence}\ \mathrm{condition}\ \mathrm{changing,}\ \mathrm{the}\ \mathrm{model}\ \mathrm{is}\ \mathrm{challenged.}$$

*This is a challenge, not a falsification. The model predicts that singularities are observer-relative. If a singularity appears independently of the observer's coherence relation, the model is challenged.*

**Formal Statement — Criterion 5 Details.** The model predicts that singularities are regions of maximal constraint on coherent traversal within $\mathcal{M}_C^O(h,x)$. They are not intrinsic features of the Library $\mathcal{M}$; they are features of the observer's relation to the Library. If a singularity appears without the observer's coherence condition changing, the model is challenged.

*This criterion is testable by examining whether singularities are observer-relative. If a singularity is observer-independent, the model is challenged.*

The pathological coherence breakdown criterion is a direct consequence of the NSFG framework's relational coherence structure. Singularities are not intrinsic to the Library; they are features of the observer's relation to the Library. If a singularity is observer-independent, the framework is challenged.

**Summary of Falsification Criteria**

- Criterion 1: Coherence-Expansion Mapping — Falsification: $H(z) = -\kappa_C \frac{d}{dt}(\ln C(z))$ must hold. If not, the model is falsified.
- Criterion 2: Black Hole Observations — Challenge: Hawking radiation must carry coherence signatures. If not, the model is challenged.
- Criterion 3: Dyadic Instability — Challenge: A pure dyad must be unstable. If a stable pure dyad exists, the model is challenged.
- Criterion 4: O(1) Computational Core — Challenge: The computational cost per tick must be $\mathcal{O}(1)$, independent of $|\mathcal{M}|$ or $h$. If a theory requires exponentially increasing resources, the model is challenged.
- Criterion 5: Pathological Coherence Breakdown — Challenge: Singularities must be observer-relative. If a singularity appears without the observer's coherence condition changing, the model is challenged.

The falsification criteria establish NSFG as a testable scientific framework. The coherence-expansion mapping is a strong falsification criterion: if it does not hold, the framework is wrong. The other criteria are challenges: if they are not met, the framework needs refinement. This is a healthy scientific posture: the framework is falsifiable and testable, not a closed belief system.

The criteria in this section are derived strictly from the axioms and definitions established earlier, without introducing new assumptions. Together, they set the stage for a comparative assessment: what NSFG can do that other frameworks cannot, and where its unique contributions to the understanding of singularities lie.
