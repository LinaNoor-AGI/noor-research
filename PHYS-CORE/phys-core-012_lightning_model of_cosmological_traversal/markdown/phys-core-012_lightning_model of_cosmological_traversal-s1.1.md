# 1.1 The Paradox of Forward Coherence

PHYS-CORE-004 established the Library (L) as a static totality containing **ALL** states and configurations. PHYS-CORE-009 §1.1 formalizes this as the inverse-limit construction:

$$
\mathcal{M} \cong NS = \lim_{k\to\infty} NS_k
$$

This is a static totality with no exterior. There is no vantage point outside the Library from which its contents could be observed or modified.

In earlier local models, motion is defined as the persistence of a coherent motif through a sequence of allowed transformations. From the internal perspective of the observer, it appears as though the universe evaluates coherence step-by-step, generating the future by selecting only the pathways that maintain the coherence threshold.

However, within a static totality, this "forward-generation" view presents a paradox. If the Library does not actively restrict adjacency—if all states are adjacent, as the unconstrained adjacency relation $x \rightsquigarrow y$ suggests—what mechanism confines the observer solely to coherent paths? The observer should be free to wander into incoherent states, yet experience reports only coherent forward progression.

The answer cannot be a "forward-pushing" physical force. Such a force would reintroduce the very handwaving the coherence ontology sought to eliminate. It would require an external agent or mechanism that evaluates each transition and permits or denies it—a homunculus that the framework cannot accommodate.

The Lightning Model resolves this paradox by providing a retrocausal selection mechanism. It is not a metaphor; it is the operational mechanism derived from the XOR ground condition $H = G_{16}(\mathcal{M}) = \mathcal{M} \oplus \neg\mathcal{M}$ of PHYS-CORE-009. The static Library contains all paths; the Lightning Model is the mechanism by which coherent paths are selected retrocausally.

This reframes the problem. The question is no longer "How does the observer choose a coherent path?" but rather "What mechanism selects the coherent path from the static totality?" The answer is retrocausal: the path is locked in from its terminal attractor, not pushed forward from its origin.

## Mathematics

**Library as Total Domain (from PHYS-CORE-004 and PHYS-CORE-009)**

$$
\mathcal{M} \cong NS = \lim_{k\to\infty} NS_k
$$

- *Role:* definition
- *Variables:*
  - $\mathcal{M}$ — The Library: the static totality of all logically admissible configurations.
  - $NS$ — Noor Sphere: the inverse-limit construction of recursive fiber bundles over $S^2$.
  - $NS_k$ — The $k$-th finite-stage Noor sphere in the inverse-limit construction.
- *Assumptions:* The inverse limit exists and is well-defined. The construction is self-contained and does not require external axioms.

**Ontological Completeness**

$$
\forall C \text{ internally describable } \Rightarrow C \in \mathcal{M}
$$

- *Role:* axiom
- *Variables:*
  - $C$ — An internally describable configuration.
  - $\mathcal{M}$ — The Library.
- *Assumptions:* The Library contains every configuration that can be described from within itself. There is no exterior vantage point from which to describe configurations not in the Library.

**No Exterior**

$$
\nexists \Omega' : \mathcal{M} \subset \Omega'
$$

- *Role:* axiom
- *Variables:*
  - $\Omega'$ — A hypothetical exterior superset of the Library.
  - $\mathcal{M}$ — The Library.
- *Assumptions:* The totality is closed. There is no outside of the Library.

**Staticity Axiom**

$$
\mathcal{M}(t) = \mathcal{M} \quad \forall t \in \mathbb{R}
$$

- *Role:* axiom
- *Variables:*
  - $\mathcal{M}(t)$ — The Library as a function of time $t$.
  - $t$ — A temporal parameter.
- *Assumptions:* The Library does not change. Observed temporality arises solely from projection of coherence gradients along descent paths.

**Unconstrained Adjacency**

$$
x \rightsquigarrow y
$$

- *Role:* definition
- *Variables:*
  - $x$ — A state in the Library.
  - $y$ — A state in the Library.
  - $\rightsquigarrow$ — Adjacency relation: $x$ can transition to $y$.
- *Assumptions:* There is no pre-existing restriction on which transitions are possible. All states are adjacent in the Library.

## Definitions

**Library** ($\mathcal{M}$) — The static totality of all logically admissible configurations. It is the inverse-limit construction $NS = \lim_{k\to\infty} NS_k$, with no exterior and no temporal variation.

- *Scope:* Ontological foundation of the coherence framework.

**Configuration** ($C$) — An internally describable state or structure within the Library.

- *Scope:* Any element of the Library.

**Static Totality** — A closed system containing **ALL** configurations, with no exterior and no temporal variation.

- *Scope:* The ontological characterization of the Library.

**Adjacency** ($\rightsquigarrow$) — The relation between any two states in the Library, indicating that a transition is possible.

- *Scope:* Unrestricted in the Library; all states are adjacent.
