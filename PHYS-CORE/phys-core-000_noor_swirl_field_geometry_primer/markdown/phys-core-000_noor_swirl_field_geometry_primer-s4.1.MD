## 4. No Exterior, No Privileged Perspective

The static-totality interpretation raises a precise reference problem: can there be a privileged perspective from which the Library as a whole is resolved, ordered, or judged while that perspective itself remains external to the relational structure being described? This section examines that problem formally and derives the absence of a privileged God's-eye perspective from the closure construction, without introducing an additional physical or observational axiom.

**Definition.** Let $\mathcal{M}$ denote the Library. The Library is formally characterized through the closure relation $\mathcal{M} := \mathrm{Closure}_{D}(\oplus)$, but this closure is not interpreted as a temporal generation process. An external candidate is a proposed configuration or perspective $\Omega$ satisfying $\Omega \notin \mathcal{M}$ while simultaneously being invoked as a reference for resolving relations within $\mathcal{M}$.

The argument proceeds in five steps. Suppose $\Omega$ is proposed as an external reference capable of resolving or judging the Library as a whole. If $\Omega$ is represented as a configuration using the same formal machinery that defines the axiomatic domain, then that representation is part of the formal configuration domain to which the closure construction applies. If the represented configuration $\Omega$ is admitted by the primitive operation and is reachable under the closure relation, then the closure places it within the Library. The proposed configuration can therefore not simultaneously be an internally represented XOR-generable configuration and remain outside the Library. The important consequence is not that every conceivable exterior is metaphysically impossible, but that an internally represented configuration cannot acquire privileged external status merely by being declared external.

The deeper issue is relational rather than merely set-theoretic. A perspective does not become a privileged reference frame simply because it is postulated outside the Library. To resolve distinctions within $\mathcal{M}$, an external perspective would require a specified relation connecting it to the configurations being resolved. If that relation is not part of the formal system, the perspective contributes no additional internal coherence rule. If the relation is introduced into the formal system, then the relation itself becomes part of the described structure and must be accounted for by the same ontology.

This result must not be confused with the claim that nothing can exist beyond the Library in every imaginable philosophical or mathematical sense. The axiomatic floor makes a narrower claim. An object or perspective that is completely undefined within the formal system is simply outside the theory's vocabulary, and no conclusion about its existence is derived. An object or perspective that is represented within the formal machinery, however, cannot be granted a special ontological status merely by labeling it external. A proposed object may have no representation within the formal system; in that case, the axiomatic floor makes no derivation concerning its existence, structure, or relation to the Library. A proposed exterior that is represented as a configuration using the same formal machinery is no longer available as an unexplained privileged reference; if that configuration is admitted to the XOR-generable domain, it belongs to the Library under the closure characterization. And a perspective may be verbally postulated as external without thereby acquiring a coherence relation to the Library; without an internally specified relation, it supplies no God's-eye resolver for distinctions within the Library.

The conclusion is deliberately weaker than a claim that nothing can exist beyond the Library in every imaginable philosophical or mathematical sense. The axiomatic result concerns the availability of a privileged external reference relation. Such a relation cannot be assumed merely by postulating an exterior. It must either remain undefined, in which case the axiomatic floor derives nothing from it, or be represented within the formal structure, in which case it loses its status as an unexplained privileged standpoint. A describable XOR-generable configuration cannot remain an unexplained privileged exterior to $\mathcal{M}$, and an undefined exterior supplies no derived coherence relation to $\mathcal{M}$. Therefore the axiomatic floor provides no privileged external God's-eye resolver. Reference must instead be established relationally within the formal structure.

**Definition.** $\mathcal{M} := \mathrm{Closure}_{D}(\oplus)$

**Formal Statement.** $\Omega \notin \mathcal{M}$

**Formal Statement.** $\Omega\ \mathrm{internally\ represented} \Rightarrow \Omega \in D$

**Formal Statement.** $\Omega \in D \land \Omega\ \mathrm{is\ XOR\text{-}generable} \Rightarrow \Omega \in \mathrm{Closure}_{D}(\oplus)$

**Formal Statement.** $\Omega \in \mathrm{Closure}_{D}(\oplus) \Rightarrow \Omega \in \mathcal{M}$

**Formal Statement.** $\Omega \in \mathcal{M} \land \Omega \notin \mathcal{M} \Rightarrow \bot$

**Definition.** $R_{\Omega}: \Omega \times \mathcal{M} \rightarrow \mathcal{R}$

**Formal Statement.** $R_{\Omega}\ \mathrm{not\ specified} \Rightarrow \mathrm{no\ derived\ privileged\ coherence\ relation}$

**Formal Statement.** $R_{\Omega}\ \mathrm{specified\ within\ the\ formal\ system} \Rightarrow R_{\Omega}\ \mathrm{is\ part\ of\ the\ described\ structure}$

**Formal Statement.** $\mathrm{no\ privileged\ external\ reference\ relation\ is\ derivable\ from\ the\ axiomatic\ floor}$

**Logical Invariants**

- XOR remains the sole primitive.
- The Library remains a definition rather than an additional axiom.
- Closure is explicitly taken over the domain D.
- No physical space is introduced.
- No physical time is introduced.
- No causality is introduced.
- No consciousness is introduced.
- No privileged observer is introduced.
- Inaccessibility is not treated as erasure.
- The Library is not treated as a physical container.
- The distinction between formal non-membership and unknowability is preserved.
- The conclusion is restricted to describable privileged exteriors.

Without a privileged exterior supplying an absolute resolution rule, observer resolution must be treated as relational rather than universal. The next construction can therefore define observerhood structurally from persistent distinguishability, while keeping the observer relationally situated with respect to the unchanged totality $\mathcal{M}$.

### 4.1 The Exterior Problem

The static-totality interpretation raises a precise reference problem: can there be a privileged perspective from which the Library as a whole is resolved, ordered, or judged while that perspective itself remains external to the relational structure being described? At this stage, an exterior is not defined geometrically or physically. It is defined formally as a proposed configuration or perspective that is both relevant to the description of the Library and claimed to stand outside the Library's relational domain.

**Definition.** Let $\mathcal{M}$ denote the Library. The Library is formally characterized through the closure relation $\mathcal{M} := \mathrm{Closure}_{D}(\oplus)$, but this closure is not interpreted as a temporal generation process. The argument proceeds as follows.

1. Suppose $\Omega$ is proposed as an external reference capable of resolving or judging the Library as a whole. *Formal form:* $\Omega \notin \mathcal{M}$.
2. If $\Omega$ is represented as a configuration using the same formal machinery that defines the axiomatic domain, then that representation is part of the formal configuration domain to which the closure construction applies. *Formal form:* $\Omega\ \mathrm{is\ internally\ represented} \Rightarrow \Omega \in D$.

4. The proposed configuration can therefore not simultaneously be an internally represented XOR-generable configuration and remain outside the Library. *Formal form:* $\Omega \in \mathcal{M} \land \Omega \notin \mathcal{M} \Rightarrow \bot$.
5.
