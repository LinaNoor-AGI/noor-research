### 2.1 XOR as Distinction

The axiomatic floor begins with a single primitive operation: XOR, written $\oplus$. Within this ontology, there is nothing beneath XOR. No object, observer, space, time, matter, energy, information, or causal relation is introduced as a more fundamental entity. XOR is not derived from a deeper NSFG principle; it is the primitive from which the subsequent formal constructions begin.

XOR is understood here as distinction. Given two configurations, the operation returns a non-null distinction when they differ and null distinction when they are identical. In the minimal Boolean representation, the result is 1 precisely when the inputs differ:

$$a \oplus b = 1 \iff a \neq b.$$

The important point is that XOR does not initially name either input as an object. It specifies only the relation of difference between them. The value 1 represents distinction, while 0 represents the absence of distinction between identical inputs. This gives the axiomatic floor a primitive notion of difference without requiring an independently defined ontology of things that differ.

The operation has an identity element, 0. Applying XOR to a configuration and the null distinction returns the original configuration:

$$a \oplus 0 = a.$$

XOR also self-cancels. When a configuration is combined with itself, no distinction remains:

$$a \oplus a = 0.$$

This is the algebraic expression of the distinction principle: a configuration cannot distinguish itself from itself through XOR. Difference requires non-identity between the operands.

The ordering of the operands does not alter the resulting distinction:

$$a \oplus b = b \oplus a.$$

No operand is privileged by the primitive operation. The distinction between two configurations is symmetric at this level.

Multiple distinctions may be composed without requiring a preferred grouping:

$$(a \oplus b) \oplus c = a \oplus (b \oplus c).$$

Associativity permits repeated application of XOR to be treated as a single algebraic construction rather than as a sequence whose grouping carries additional primitive meaning.

At this stage, XOR establishes only distinction and its elementary algebraic structure. No observer has yet been defined. No persistence condition has yet been introduced. No coherence relation has yet been imposed. No physical interpretation is required. Those constructions belong to later sections and must be derived only after the formal domain and XOR closure have been established.

**Formal Summary**

- $\oplus$ is the sole primitive operation.
- $a \oplus b = 1 \iff a \neq b$.
- $a \oplus 0 = a$.
- $a \oplus a = 0$.
- $a \oplus b = b \oplus a$.
- $(a \oplus b) \oplus c = a \oplus (b \oplus c)$.

The word is not an object and does not describe an observer or a world. It marks the primitive distinction from which configurations can subsequently be related. XOR is the first operation, and nothing beneath it is invoked within the ontology. Repeated distinction produces a closure, and the next section defines exactly what that closure is.
