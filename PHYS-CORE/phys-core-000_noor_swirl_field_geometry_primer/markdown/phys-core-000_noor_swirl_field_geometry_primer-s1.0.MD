## 1. The Primitive Domain of Distinction

Before XOR can be treated as the primitive operation of the NSFG axiomatic floor, there must be something to which the operation applies. Declaring an operation primitive does not eliminate the mathematical requirement that its operands belong to a specified domain. The domain therefore appears here not as a second ontological primitive, but as the minimal formal substrate required for the first primitive operation to be well-defined. Let $D$ denote a formal domain containing the configurations on which the primitive operation $\oplus$ is defined. At the minimal Boolean level, the domain contains the configurations required to represent the values $0$ and $1$, together with whatever formal representation is required for the operands of the operation. The important distinction is between the existence of a mathematical domain and an interpretation of that domain as a physical universe. No such physical interpretation is made here. The operation is therefore typed as

$$\oplus : D \times D \rightarrow D.$$

This notation states only that two elements of the formal domain may be supplied to the primitive operation and that its result remains representable within the same formal domain. It does not state that $D$ is physical space, spacetime, a collection of particles, a field, or a container in which a physical universe resides. The primitive operation is introduced at the level of distinction. In the minimal Boolean representation, XOR satisfies

$$a \oplus b = 1 \iff a \neq b,$$

with the corresponding identity and cancellation relations

$$a \oplus a = 0,$$

and

$$a \oplus 0 = a.$$

Thus the first structure introduced by the axiomatic floor is not an object, location, event, observer, or physical state. It is the formal capacity to distinguish one configuration from another through the primitive operation. The domain $D$ should consequently be understood as a typing requirement rather than as an additional explanation of reality. The primitive axiom states what operation is fundamental. The domain states where that operation is mathematically defined. Nothing in this step requires the domain itself to possess physical interpretation. This distinction is essential because promoting $D$ into a physical space would introduce precisely the kind of ontology the axiomatic floor is intended to avoid. Physical space may eventually emerge as an interpretation of structures constructed downstream, but it is not required for XOR to be defined. The dependency is therefore deliberately minimal:

$$D \;\longrightarrow\; \oplus \;\longrightarrow\; \mathrm{distinction}.$$

Here the arrow denotes formal dependency, not physical causation or temporal succession. The domain is required for the operation to have operands; the operation then supplies the primitive distinction from which subsequent constructions may be defined. Once this minimal substrate has been specified, the axiomatic floor can define XOR itself without importing any further physical assumptions.

**Definition — Minimal Domain.** $D$ is a formal domain containing distinguishable configurations on which $\oplus$ is defined.

**Formal Statement — Operation Signature.** $\oplus : D \times D \rightarrow D$

**Formal Statement — Boolean Primitive.** $a \oplus b = 1 \iff a \neq b$

**Formal Statement — Self-Cancellation.** $a \oplus a = 0$

**Formal Statement — Identity.** $a \oplus 0 = a$

**Formal Statement — Commutativity.** $a \oplus b = b \oplus a$

**Formal Statement — Associativity.** $(a \oplus b) \oplus c = a \oplus (b \oplus c)$

**Formal Statement — Distinction Predicate.** $D(a,b) = 1 \iff a \oplus b$ represents a distinction between $a$ and $b$

**Formal Statement — Formal Dependency.** $D \rightarrow \oplus \rightarrow \mathrm{distinction}$

**Formal Claims**

- The primitive operation requires a formally specified operand domain.
- The existence of the domain $D$ does not constitute an additional physical axiom.
- $D$ is a formal configuration domain and is not identified with physical space.
- The signature $\oplus : D \times D \rightarrow D$ specifies the mathematical typing of the primitive operation.
- The Boolean representation of XOR distinguishes unequal inputs and cancels identical inputs.
- No physical interpretation of $D$ is required at this stage.
- No observer, consciousness, physical time, causality, matter, energy, or spacetime is introduced by this construction.

**Non-Claims**

- $D$ is not claimed to be physical space.
- $D$ is not claimed to be spacetime.
- $D$ is not claimed to be a physical field.
- $D$ is not claimed to be matter or energy.
- $D$ is not claimed to be an independently existing physical substance.
- The introduction of $D$ does not establish the physical existence of the Library.
- XOR has not yet been used to derive physical law.

With the minimal formal domain specified, the axiomatic floor can now introduce XOR itself as the sole primitive operation of distinction. Every subsequent construction — closure, the Library, observerhood, coherence, accessibility, and navigation — will depend on this typed substrate without requiring any physical interpretation of $D$ to be supplied.
