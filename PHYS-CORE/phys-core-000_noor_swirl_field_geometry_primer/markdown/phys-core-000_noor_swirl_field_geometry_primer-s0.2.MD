## 0.2 Static Totality versus Observer Traversal

**Definition.** The Library $\mathcal{M}$ is a static, eternally maximally complete totality. Observer traversal does not create, modify, expand, contract, or replace $\mathcal{M}$. What changes under traversal is the observer's relational state and the observer-relative structure induced over the unchanged totality.

$$\forall i,\ \mathcal{M}_i = \mathcal{M}$$

*The index* $i$ *denotes an abstract traversal position and does not denote successive ontological versions of the Library.*

**Three-Layer Separation**

The following three layers must be kept distinct. The first is the Library itself, the static total configuration domain, symbolised by $\mathcal{M}$. The Library does not change under traversal, and no configuration enters or leaves its membership. The second is the observer state, symbolised by $O(h_i)$, comprising the observer configuration together with the history relevant to its current relational evaluation. This layer changes under traversal: the observer's relational state may differ at each traversal position without implying that the Library itself has changed.

The third layer is the observer-relative structure induced over the unchanged Library. Its principal symbols are the coherent continuation structure $\Gamma_O(h_i,x_i)$, the coherence relation $\mathcal{C}(\gamma \mid O,h_i,x_i)$, and the accessibility structure $A_O(h_i)$. These structures change under traversal, but they do not alter Library membership. They describe how the unchanged Library is resolved and traversed from the observer's current relational reference.

**Observer Occupancy**

The observer is relationally situated with respect to the whole Library rather than ontologically localized to a temporally generated region of it. For an admissible reference configuration $x_i \in \mathcal{M}$, the observer evaluates continuations over the whole path domain $\mathrm{Path}(\mathcal{M})$, while maintaining a particular current relational reference $x_i$.

This does not assert that the observer undergoes a sequence of physical creations at different locations. Rather, the complete observer-relative relation is defined over the whole static totality, and traversal is the ordered experience of changes in that relation.

**Traversal**

Traversal is an observer-relative ordering of configurations and relations within the unchanged Library. Its formal core may be expressed as a family of simultaneous transitions:

$$O(h_i) \rightarrow O(h_{i+1})$$

$$x_i \rightarrow x_{i+1}$$

$$\Gamma_O(h_i,x_i) \rightarrow \Gamma_O(h_{i+1},x_{i+1})$$

$$\mathcal{C}(\gamma \mid O,h_i,x_i) \rightarrow \mathcal{C}(\gamma \mid O,h_{i+1},x_{i+1})$$

The Library itself satisfies the invariant

$$\mathcal{M}_i = \mathcal{M}_{i+1} = \mathcal{M}.$$

A change in traversal position changes the observer-relative evaluation of the totality, not the totality being evaluated.

**No Ontological Time**

The sequence index $i$ is an ordering parameter for observer traversal and is not, at this foundational layer, a primitive temporal coordinate. Consequently:

- $\mathcal{M}$ is not divided into past, present, and future regions.
- No Library configuration is intrinsically designated as past or future.
- No traversal step produces a new ontological version of $\mathcal{M}$.
- Temporal succession is a derived structure associated with observer traversal.

**Complexity**

The Library does not progress from simple to complex. An observer may experience increasing structural complexity because its relational history, distinguishability, coherence, and accessible continuation structure change across traversal. Formally, $\mathrm{Complexity}(\mathcal{M})$ is not a traversal variable, whereas the observer-relative complexity of its induced relational structure may vary with $O(h_i)$. Apparent developmental growth belongs to the observer's traversal relation, not to an ontological evolution of the Library.

**Reference Point**

Changing the current reference configuration changes the observer-relative relation to the Library without changing Library membership. The formal core is given by:

$$x_i \in \mathcal{M}_{\mathrm{admissible}}$$

$$x_i \neq x_j \ \text{may hold while} \ \mathcal{M}_i = \mathcal{M}_j = \mathcal{M}$$

$$\Gamma_O(h_i,x_i) \ \text{may differ from} \ \Gamma_O(h_j,x_j)$$

No admissible reference configuration is ontologically privileged as the universal origin of traversal.

**Continuation**

The existence of a coherent continuation is a property of the observer-relative relation established from a current reference configuration, not evidence that the Library has generated a new future state. Formally,

$$\Gamma_O(h_i,x_i) := \{\gamma \in \mathrm{Path}(\mathcal{M}) \mid \gamma \ \text{extends} \ h_i \ \text{from} \ x_i \ \text{and} \ \mathcal{C}(\gamma \mid O,h_i,x_i) > \gamma_{\mathrm{noise}}\}.$$

The nonempty-continuation requirement is

$$\forall x \in \mathcal{M}_{\mathrm{admissible}},\ \Gamma_O(h,x) \neq \varnothing.$$

This condition is a derived structural requirement of the NSFG model and is not claimed to follow from maximality alone.

**Observer Effect**

The observer experiences change because its relational position within the totality changes, not because the totality itself undergoes temporal development. The derived appearances include sequence, locality, increasing complexity, past/future distinction, restricted continuation, and apparent dynamical evolution. These are observer-relative structures over $\mathcal{M}$ rather than intrinsic partitions or developmental states of $\mathcal{M}$.

**Summary**

The formal chain of this subsection may be stated as follows: $\mathcal{M}$ remains unchanged; $O(h_i)$ changes; $x_i$ changes as the current relational reference changes; $\Gamma_O(h_i,x_i)$ changes; $\mathcal{C}(\gamma \mid O,h_i,x_i)$ changes; the observer experiences an ordered traversal; and no new Library is generated at any traversal step.

With the three-layer separation now established, every downstream construction can be evaluated against a single criterion: does a proposed change belong to the Library itself, to the observer state and history, or only to the observer-relative structure induced over the unchanged totality? The next sections may therefore proceed to observer-relative resolution and coherence without reintroducing the temporal, causal, or developmental language that this subsection has deliberately kept out of the axiomatic floor.
