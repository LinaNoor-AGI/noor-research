## 3. The Library as XOR Closure

The primitive operation $\oplus$ does not by itself specify a physical ontology or a temporal process. It specifies an operation of distinction on a formal domain $D$. Closure then provides the mathematical condition under which a collection of configurations remains closed under that operation. The resulting Library is not interpreted as something progressively generated by applying XOR. Rather, closure characterizes the structural completeness of a totality treated as static and complete.

**Definition — Formal XOR Closure.** Let $D$ be the formal domain on which $\oplus$ operates, and let $G \subseteq D$ be a specified set of configurations used as mathematical generators for a representation. The XOR closure of $G$ in $D$, written $\mathrm{Closure}_{D}(\oplus;G)$, is the smallest subset $S \subseteq D$ such that $G \subseteq S$ and, for every $x,y \in S$, $x \oplus y \in S$.

$$\mathrm{Closure}_{D}(\oplus;G) = \bigcap\{S \subseteq D \mid G \subseteq S \land \forall x,y \in S,\; x \oplus y \in S\}$$

The closure notation specifies a mathematical characterization. It does not imply that the elements of the closure are generated sequentially, that one configuration existed before another, or that a member of $G$ constitutes an ontological first state. The generating set is representational: it supplies a description from which the closed structure may be mathematically specified, but it does not become an origin of the totality.

**Definition — Static Library.** The Library $\mathcal{M}$ is the maximally complete, unbounded totality satisfying XOR closure and self-containment with respect to the formal resources of the system. Closure describes a structural property of $\mathcal{M}$; it is not a temporal, developmental, or ontological mechanism by which $\mathcal{M}$ comes into existence.

**Library closure property.**

$$\forall x,y \in \mathcal{M},\quad x \oplus y \in \mathcal{M}$$

*Applying XOR to configurations already contained in the Library yields a configuration that remains within the Library.*

The formal closure construction may be used to characterize an XOR-closed structure, but the semantic definition of the Library is stronger than closure minimality alone. The Library is treated as the complete static totality admitted by the formal ontology, not merely as a finite result produced by a particular generating history.

**Definition — Self-Containment.** The Library is self-contained with respect to its formal resources: no configuration outside $\mathcal{M}$ can function as a privileged exterior if that configuration is itself definable within the system using $\oplus$, elements of $\mathcal{M}$, and the formal domain $D$.

**No describable privileged exterior.**

$$\neg\exists z \notin \mathcal{M}\;\text{such that }z\text{ is definable within the system using only }\oplus\text{ and elements of }\mathcal{M}\text{ over }D\text{ as a privileged exterior}$$

*A formally describable candidate for a privileged exterior cannot supply a genuinely external reference to the totality.*

This condition does not assert that literal physical exteriority is independently impossible. It establishes a formal boundary condition: a privileged exterior that is describable using the same formal resources cannot remain external to the totality it is supposed to stand outside of. Any such candidate is already part of the formal relational structure under consideration.

**Definition — Relational Completeness.** The Library is relationally complete in the following formal sense: for every relation $R$ in the represented relation family $\mathcal{R}$, and for configurations $x,y \in \mathcal{M}$, if $R(x,y)=1$, then the relation is representable within $\mathcal{M}$ without requiring $R$ itself to be introduced as a primitive of the system.

**Relational completeness of the Library.**

$$\forall R \in \mathcal{R},\;\forall x,y \in \mathcal{M},\; R(x,y)=1 \Rightarrow R\text{ is representable within }\mathcal{M}\text{ without requiring }R\text{ to be a primitive of the system}$$

*The Library is not merely a collection of configurations. Relations among configurations can be represented within the same totality without becoming additional axioms.*

This relational completeness is important because later constructions operate through relations rather than through a second primitive ontology. Observer-relative distinguishability, coherence, accessibility, and related structures can therefore be represented over the Library without requiring the Library itself to be replaced by a domain-specific substrate. The relation is a structure over configurations; it is not an additional primitive alongside $\oplus$.

The statement of relational completeness does not mean that every possible relation has been physically instantiated, empirically observed, or independently derived at this stage. It states only that relations required by the formal development can be represented within the totality without requiring a privileged external relational substrate.

**Definition — XOR Termination Singleton.** The unique singleton termination class $\mathcal{Z}$ is the subset of configurations satisfying self-cancellation as a fixed-point condition under XOR: $\mathcal{Z} := \{z \in D \mid z \oplus z = z\}$. Under the Boolean XOR identities, this set is exactly $\{0\}$.

**Termination singleton.**

$$\mathcal{Z} := \{z \in D \mid z \oplus z = z\} = \{0\}$$

*The XOR identity is the unique element satisfying the stated self-fixed condition.*

For every $x \in \mathcal{M}$, self-cancellation gives $x \oplus x = 0$, and therefore $x \oplus x \in \mathcal{Z}$. The singleton $\mathcal{Z}$ is consequently internal to the Library whenever $\mathcal{M}$ is nonempty and XOR-closed. It is not an exterior, boundary, edge, or region beyond the Library.

**Universal self-cancellation into 𝒵.**

$$\forall x \in \mathcal{M},\quad x \oplus x = 0 \in \mathcal{Z} \subseteq \mathcal{M}$$

*Every Library configuration self-cancels to the internal XOR identity.*

The identity element also satisfies $0 \oplus x = x$. Thus $0$ is not a point outside the relational structure but its internal XOR identity. When the recursive bounce relation $(x \oplus y) \oplus y = x$ is evaluated at $y=0$, it reduces immediately to $(x \oplus 0) \oplus 0 = x$. The distinction has therefore reached the identity state in which the second application introduces no new change.

**Identity-state degeneration.**

$$(x \oplus 0) \oplus 0 = x$$

*At the identity state, recursive XOR application introduces no additional distinction.*

The relation $x \sim y \iff x \oplus y = 0$ defines equality for Boolean XOR, since $x \oplus y = 0$ holds exactly when $x=y$. Consequently, each configuration forms its own equivalence class, and $\mathcal{Z}=\{0\}$ is specifically the singleton equivalence class containing the XOR identity.

**Equivalence relation associated with XOR.**

$$x \sim y \iff x \oplus y = 0\quad\Longleftrightarrow\quad x=y$$

*Under Boolean XOR, cancellation to zero occurs exactly for identical configurations.*

𝒵 is therefore complementary to the non-degenerate relational structure in a structural sense: it represents completed self-cancellation or termination of distinction rather than an exterior to distinction. The complement $\mathcal{M}\setminus\mathcal{Z}$ contains configurations that are not the XOR identity, while $\mathcal{Z}$ contains the completed identity state. This is termination versus non-degenerate distinction, not inside versus outside.

**Definition — Reference-Frame Neutrality.** No configuration in $\mathcal{M}$ is privileged as the ontological origin of the Library. Any admissible configuration $x \in \mathcal{M}$ may serve as an observer-relative reference configuration without becoming a privileged origin or changing the Library itself.

**Arbitrary reference invariance.**

$$\forall x \in \mathcal{M}_{\mathrm{admissible}},\quad x\text{ may serve as a relational reference without altering }\mathcal{M}$$

*Relocating the relational reference does not change the underlying Library.*

The choice of $G$ does not weaken this neutrality. A mathematical generating description may be useful for specifying the closure, but no member of $G$ acquires ontological priority merely because it was selected as a generator. Treating a generator as a privileged physical beginning would convert a representational choice into an additional axiom.

**Definition — Static Maximality.** The Library is interpreted as maximally complete relative to the formal ontology of the model. No configuration admitted by that ontology is excluded merely because it has not been encountered by an observer, lies outside an observer's current coherent continuation, or was not included in a particular traversal history.

**Static invariance.**

$$\forall i,\quad \mathcal{M}_{i}=\mathcal{M}$$

*The Library does not change as abstract observer traversal changes.*

The index $i$ in this expression is merely a formal notation for invariance and does not denote successive temporal copies of the Library. The Library does not expand, contract, become more complete, or become more complex as an observer traverses it. Changes in apparent succession or complexity belong to the observer's changing relation to the unchanged totality.

Static maximality must not be confused with closure minimality. The closure construction identifies the smallest XOR-closed subset containing a chosen generating set. The semantic interpretation of $\mathcal{M}$ as the maximally complete totality is an additional definitional condition of this axiomatic floor. It is not claimed that maximality follows mathematically from closure minimality alone.

**Definition — Whole-Library Relationality.** An observer-relative reference configuration is relationally situated with respect to the whole Library rather than occupying an ontologically isolated local portion of it. Observer state, history, resolution, and coherence determine accessible relations; they do not determine membership in $\mathcal{M}$.

**Accessibility as a relation over the Library.**

$$\mathcal{A}_{O}(h,x) \subseteq \mathcal{M},\qquad x \in \mathcal{M}$$

*Observer-relative accessibility is a relation over Library configurations and does not redefine Library membership.*

A configuration can therefore remain a member of $\mathcal{M}$ even when it is inaccessible, indistinguishable, or incoherent relative to a particular observer. Accessibility is a relation over the Library rather than a mechanism for creating or deleting Library membership.

The same separation applies to 𝒵. Reaching the termination singleton does not erase a configuration from the Library. Rather, self-cancellation maps the configuration's XOR relation to the internal identity state $0$. Termination is therefore a relational property of the operation, not an ontological boundary of the totality.

At the axiomatic floor, membership in $\mathcal{M}$ carries no implication of persistence, coherence, observability, accessibility, physical realization, consciousness, or causal participation. Those properties belong to later relational constructions defined over the unchanged Library.

The central distinction is therefore between closure and generation. Closure states that the Library is structurally invariant under XOR. It does not describe a universe being assembled one XOR operation at a time. Likewise, observer traversal does not cause configurations to become members of the Library. The observer's relation changes; $\mathcal{M}$ does not.

**Logical Invariants**

- XOR is the only primitive operation of distinction.
- D is the minimal formal domain required for XOR to operate.
- G specifies generating configurations and is not an additional primitive.
- The Library is a definition rather than an axiom.
- A set can be closed under an operation; the operation itself should not be called closed.
- The Library is XOR-closed.
- Closure is a mathematical characterization, not a temporal or ontological generation process.
- The Library is static, maximally complete, unbounded, and invariant under traversal.
- The Library is relationally complete in the stated representational sense.
- The Library is self-contained with respect to describable privileged exteriors.
- The termination singleton 𝒵 is internal to the Library.
- Library membership is distinct from persistence, coherence, observability, and accessibility.
- Inaccessibility is not erasure.
- There is no privileged coordinate, origin, generator, worldline, or observer.
- Relations required by later constructions are represented within the Library without becoming additional primitives.
- The abstract traversal index is not physical time.
- The Library does not generate future events.
- No physical ontology is assumed at this stage.

With the Library now characterized as a static, XOR-closed, self-contained, and relationally complete totality, the next question is whether a candidate described as external to the Library can remain external when it is itself definable using the same formal machinery. The formal problem of a describable privileged exterior therefore becomes the next construction.
